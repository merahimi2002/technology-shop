# نقشه راه صفحه‌ها و پنل‌ها

فهرست‌های جدید کاربران، محصولات و سفارش‌ها از [صفحه‌بندی مشترک](DESIGN_SYSTEM.md#صفحه‌بندی-مشترک) استفاده می‌کنند.

ورود و ثبت‌نام در صفحهٔ مستقل حساب فعال‌اند. وضعیت پیاده‌سازی جاری در [معماری](ARCHITECTURE.md) و برنامهٔ ذخیره‌سازی تصاویر محصول در [TODO](TODO.md#ذخیره-و-آپلود-عکس) ثبت شده است.

- [x] نمایش و ویرایش اطلاعات حساب و مدیریت عکس پروفایل.
- [x] تغییر رمز عبور؛ حساب OWNER تابع محدودیت‌های [حفاظت مالک](SECURITY.md#حفاظت-مالک) است.
- [x] بازیابی رمز عبور در صورت [پیکربندی ارسال ایمیل](DEVELOPMENT.md#ایمیل-بازیابی-رمز).
- [x] پوستهٔ مستقل پنل، سایدبار جمع‌شونده و کشوی موبایل برای مدیر و مالک.
- [x] جداسازی داشبورد فعلاً خالی و صفحهٔ کاربران.
- [ ] ابزارهای مدیریت فروشگاه در پنل.
- [x] صفحه مدیریت کاربران با عکس پروفایل، جست‌وجو، فیلتر، صفحه‌بندی و کنترل دسترسی سروری.
