# توسعه و بررسی پروژه

## اجرا

Node.js شاخه ۲۴ و npm شاخه ۱۱؛ محیط فعلی Node 24.11.1 و npm 11.6.2 است.

```bash
npm ci
npm run dev
npm run lint
npm run typecheck
npm run format:check
npm run build
```

## تست سبک

فقط Vitest با محیط Node، یک worker و بدون اجرای موازی فایل‌ها تنظیم شده است.
تست‌های منطق تجاری در tests/**/*.test.ts قرار می‌گیرند. هنوز تست تجاری نداریم؛ دستور test در نبود تست موفقیت ساختگی گزارش نمی‌کند.

```bash
npm test
npm run test:watch
```

Playwright، مرورگر دانلودی، axe، jsdom و CI چندمرحله‌ای فعلاً اضافه نشده‌اند. در مرحله ورود یا خرید، تست مرورگری محدود به مسیرهای ضروری اضافه می‌شود.

## وضعیت نصب

این مرحله آماده‌سازی وابستگی‌هاست. اتصال دیتابیس، مدل‌ها و migration، providerهای NextAuth، ترجمه مسیرها، فرم‌ها، Query provider و انیمیشن صفحات هنوز پیاده‌سازی نشده‌اند.
PostgreSQL یک سرویس مستقل است؛ نصب پکیج pg به معنی نصب یا اجرای سرور PostgreSQL نیست.
هیچ دیتابیس، ایمیل، درگاه یا سرویس خارجی در این مرحله متصل نشده است.

## shadcn/ui

فایل components.json برای App Router، Tailwind 4 و RTL آماده است. shadcn کتابخانه کد کامپوننت است؛ اجزا در زمان نیاز با npm exec shadcn -- add اضافه می‌شوند و باید پس از افزودن در UI بررسی شوند.

## سیاست نسخه

نسخه مستقیم وابستگی‌ها دقیق ثبت می‌شود. نسخه beta/RC نصب نمی‌کنیم. سازگاری peer dependency بدون --force و --legacy-peer-deps بررسی می‌شود.
TypeScript 6 برای API سازگار Next.js و TypeScript 7 به‌صورت alias برای کامپایلر native نصب شده‌اند.
Nodemailer شاخه ۷ با NextAuth 4 سازگار است اما آسیب‌پذیری‌های گزارش‌شده دارد؛ نصب نشد. SMTP ورود تا تصمیم سازگار و امن بعدی فعال نمی‌شود.

## نتیجه بررسی نصب — ۲۰۲۶/۱۱/۰۲

- نصب با npm و ثبت package-lock.json کامل شد؛ peer dependency ناسازگار گزارش نشد.
- lint، تولید typeهای Next.js، بررسی TypeScript و build تولیدی موفق بودند.
- npm audit --omit=dev: بدون آسیب‌پذیری گزارش‌شده.
- audit کامل: ۶ مورد در زنجیره ابزار توسعه shadcn (۲ low و ۴ moderate؛ deepmerge و minimatch و بسته‌های وابسته). npm audit fix سازگار اجرا شد؛ اصلاح پیشنهادی باقی‌مانده شامل تغییر ناسازگار shadcn است و اعمال نشد.
- هیچ تست محصولی هنوز نوشته یا اجرا نشده است؛ Vitest فقط برای منطق آینده تنظیم شده است.

## بازبینی امنیتی shadcn
